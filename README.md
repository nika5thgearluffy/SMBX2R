# Super Mario Bros. X2 Redux
This is an SMBX2 fork separate from the original SMBX2 that adds new features and new entities such as NPCs, blocks, and more.

Everything from SMBX2 Beta 5, Patch 3 and below is compatible, anything above it will NOT WORK and is not recommended to run such episodes under this engine. Use SMBX2 instead.

## How to install
Since this repo is always updated, we recommended you install git (For Windows you can download it here: https://git-scm.com/install/windows ) to download the engine, or you can use GitHub Desktop for a GUI ( https://desktop.github.com/download/ ).

If you have an older engine version, you'll need to update the engine. You can either install GitHub Desktop and add the folder you downloaded the engine to, to GitHub Desktop to pull latest commits for a GUI, or use the Command Prompt to pull latest changes.
